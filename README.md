## Biltong Frontend

Short guide to run the frontend.

### Prerequisites

- Node.js 22+
- npm
- Backend running on `http://localhost:3000`

### Run locally

```bash
cd biltong-frontend
npm install
npm run dev
```

Frontend runs on Vite default URL (usually `http://localhost:5173`).

### Run with Docker

```bash
cd biltong-frontend
docker compose up --build
```

Frontend is exposed on `http://localhost:8080`.

### Active batch data seeding (test data for now)

- The frontend displays batch sensor data generated by the backend seeding job for active batches.
- That seeded data is currently simulated/mock data for testing and development.
- Do not treat the displayed sensor values as real production sensor input yet.
